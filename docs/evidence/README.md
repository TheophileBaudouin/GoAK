# Evidence

Raw command outputs and probe results belong here. Each change should use a
dated subdirectory and preserve command, exit code, environment, and observable
scenario output verbatim. Evidence is versioned in the public repository
(<https://github.com/TheophileBaudouin/GoAK>, branch `main`).

Current evidence covers standalone KitV2, phase 2 governance, and v1
archive/restore checkpoints. Historical v1 product evidence was retired with
the deleted product; the external archive is the rollback referent.
