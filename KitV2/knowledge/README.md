# Knowledge

Knowledge is the explanation and routing layer. It is product knowledge, not
metaproject memory or evaluation governance. Canonical rules live in
`../rules/`; canonical procedures live in `../recipes/`. Catalog entries here
must explain selection, limits, evidence, and alternatives without copying
those bodies.

## Catalogs

- `catalogs/libraries/` — vetted library decisions migrated from v1.
- `catalogs/reference-projects/` — extract-only project references migrated from v1.

Add a new knowledge entry only when it has a primary source and a distinct
question that an existing rule or recipe does not answer. Empty category
folders are structural placeholders until a sourced artifact is admitted.
