# Metaproject evaluations

These methods evaluate changes to the KitV2 product and metaproject. They are
not shipped inside KitV2; consumers receive product probes and checks only.

- `architecture/` — boundaries, ownership, and minimal structure.
- `security/` — trust boundaries, secrets, scanner evidence, misuse paths.
- `testing/` — focused tests, race checks, and observable scenarios.
- `performance/` — measurements before optimization.
- `quality/` — gates, compatibility, documentation, and fresh review.
