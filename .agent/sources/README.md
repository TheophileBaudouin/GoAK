# Metaproject source registry

`Go-dev-kit-sources-et-references.md` is the strict, ordered source registry
for creating and evolving the Go Agent Development Kit. Its priorities and
categories are preserved verbatim and must be consulted before adding or
promoting sourced kit content.

The two additional source records in this directory were explicitly requested
for prompt and skill research and remain registered alongside the canonical
registry:

- `awesome-llm-apps.yaml`
- `addyosmani-agent-skills.yaml`

These are metaproject research inputs, not automatically shipped KitV2
content. Source use remains subordinate to `KIT_CHARTER.md`, the kit rules,
and the artifact admission gates. A source is promoted into KitV2 only after
separate evidence, decision, metadata, relationship, and validation work.
